# ARVIS website

Astro marketing site for ARVIS and its upcoming ADA AGENT product.

## Local development

```powershell
npm install
npm run dev
```

## Vercel

Import this repository. Use the Astro framework preset, `npm run build` as the build command, and `dist` as the output directory.

The early access form is a visual preview. Its submit button is disabled until a destination and API are configured. The contact section currently links to the early access section.
